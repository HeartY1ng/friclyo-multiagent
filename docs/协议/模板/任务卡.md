## 复现测试产物与自检

复现测试统一放在 `交付/复现测试/test_*.py`，只使用 Python 标准库。在本轮目录直接运行：

```sh
python3 -B 交付/复现测试/test_x.py
```

测试先读环境变量 `FRCLYO_REPRO_ROOT` 定位框架；未设置时使用 `<本轮目录>/输入/框架`。测试自己在入口 `$TMPDIR` 中创建临时目录（路径先 `resolve()`），把需要的源码复制进去再测试，不修改原始输入或交付。测试断言“代码修好后应有的行为”：退出 1 = 复现成功（当前代码违反期望），退出 0 = 没复现。环境、准备、导入、权限或夹具错误应保留异常信息，并显式返回 0/1 以外的退出码（例如 2）。普通 `ERROR`／`FAIL`／异常文本不会覆盖退出码，不能依赖 unittest 默认的退出 1 区分失败与错误。非零退出伴随匹配的沙箱嵌套诊断另归环境受限；跳过与环境受限均不能证明修好，完整判定见 [README](../../../README.md#复现交付测试)。

可采用下面的路径准备片段；测试夹具和执行都应放在 `with` 内，退出时清理副本：

```python
import os
from pathlib import Path
import shutil
import tempfile

round_root = Path(__file__).resolve().parents[2]
framework = Path(os.environ.get(
    'FRCLYO_REPRO_ROOT', str(round_root / '输入/框架'))).resolve()
temporary_parent = Path(os.environ['TMPDIR']).resolve()
with tempfile.TemporaryDirectory(prefix='repro-test-', dir=temporary_parent) as name:
    work = Path(name).resolve()
    source = work / 'framework'
    shutil.copytree(framework, source)
    # 在这里使用副本 source 建夹具并断言修好后应有的行为。
```

测试不能依赖真实账本、凭据或联网，不要求修改入口 HOME、TMPDIR 或缓存变量。`aw 复现` 仅对子进程设置隔离环境及兼容变量。

宿主通过 `aw 复现 <任务> <轮>` 默认选输入版；修复版用 `--框架 交付` 或 `--框架 <开发版目录>`。运行器会把 `FRCLYO_REPRO_ROOT` 设为选中树的临时副本，不能用宿主同名变量替代该选项。测试需查进程或自己开沙箱时，由获授权宿主核查后显式加 `--不套沙箱`；工人不因此获得拒绝后绕过权限的授权。
