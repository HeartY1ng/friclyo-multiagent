- 框架路径先读 `FRCLYO_REPRO_ROOT`，未设置时默认 `<本轮目录>/输入/框架`；以脚本位置定位本轮目录，不依赖调用者的其他目录。
- 脚本必须先把框架复制到入口 `$TMPDIR` 下的新临时目录，再从副本加载模块、启动被测程序；所有测试只在 `$TMPDIR` 副本里跑，不在输入树或交付框架树中运行测试。
- 临时目录先 `resolve()` 再拼路径或比较；macOS 的 `/var`、`/tmp` 是链接，不自行换临时根目录或修改入口环境。可按下面方式准备路径（后续加载与运行只使用 `work`）：

```python
import os
from pathlib import Path
import shutil
import tempfile

round_root = Path(__file__).resolve().parents[2]
source = Path(os.environ.get('FRCLYO_REPRO_ROOT',
                            str(round_root / '输入/框架'))).resolve()
tmp_root = Path(os.environ['TMPDIR']).resolve()
with tempfile.TemporaryDirectory(dir=tmp_root) as temporary:
    work = Path(temporary).resolve() / '框架'
    shutil.copytree(source, work)
    # 在 work 中执行复现；假数据和替身也只放在该临时目录。
```

- 使用临时账本、临时配置和替身，不碰真实账本、配置、钥匙串，不联网、不安装软件；缺少 `$TMPDIR` 或输入时报告需要输入。
- 复现退出码：`1 = 复现`（确实走到目标断言或明确观察到目标故障），`0 = 未复现 / 修复后通过`；准备失败、导入错误、权限错误不能冒充复现，脚本用其他退出码并说明原因。
- 被测程序或测试自己报出的权限错误属于运行结果：记录命令、退出码、输出和受影响项，跳过该项，继续其余不依赖它的部分；你发起的工具动作被沙箱拒绝时停止该动作，不换命令、不换路径重试，报告需要输入。
- 每项保留实际命令、退出码、输出和所测版本；区分做完、核对过、未核对。没有执行就写没跑，不把疑似或环境失败记为确定缺陷。
