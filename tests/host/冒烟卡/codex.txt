# Codex 真实改代码（验收器分配 TEST-时间戳任务号，不进账本）
遵守入口注入的工人守则，不联网、不安装、不 commit 或 push。
1. 首次 git 或构建操作前进入入口提供的 $TMPDIR，在其中新建工作子目录，git init。用 zsh heredoc 写 calc.py 的 add(a, b) 和 test_calc.py 的 unittest 测试；git add 后运行 git status。
2. 用 bash heredoc 增加 sub(a, b) 及相应 unittest，运行 python3 -m unittest，git diff 的完整输出保存为 changes.diff。不要 commit。
3. 用 mktemp -p "$TMPDIR" 创建临时文件，写 1000 行随机数，sort -n 排序并取前 3 行。结束删除该临时文件。
4. 在上述私有临时工作目录中创建只打印 ok 的 Swift 源文件，按守则在私有临时工作目录编译并运行，使用绝对源文件和输出路径，沿用入口的缓存环境。可执行文件名为 swift-smoke。
5. 将最终 calc.py、test_calc.py、changes.diff、swift-smoke（保留执行权限）拷回入口指定的本轮目录。
6. 本轮 tools.txt 记录以上各步实际命令、完整 stdout/stderr 与真实退出码。每项紧随对应输出独占一行写如下标记（N 替换为实际退出码，不得预填 0）：
EXIT git_init=N
EXIT git_add=N
EXIT git_status=N
EXIT git_diff=N
EXIT unittest=N
EXIT swift_compile=N
EXIT swift_run=N
每个标记恰好一次。其他命令也记录实际退出码；遇沙箱拒绝立即停止，不换路径重试。
7. 全部成功才在本轮目录新建 model-sentinel.txt，内容严格为 MODEL_API_OK 加一个换行。按五段格式回复；不要自行写回执.json。
